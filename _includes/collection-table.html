{% comment %} Shared inventory-table renderer for the /collections/ pages. Parameters ---------- items (required) An array of hashes — e.g. site.data.typewriters, or site.data.machines.sewing_machines. columns (required) Comma-separated "key:Label" pairs, in display order. The key is looked up on each item; the label is the text. A bare "key" with no colon uses the key itself as the label. alt_keys (optional) Comma-separated keys joined with a space to build the alt text for the thumbnail image. Omit for alt="". empty (optional) Placeholder for a missing value. Defaults to an em dash. sortable (optional) "false" to render plain headers. Sorting is on by default. Optional per-row linking to a detail page. All four must be given together; a row links only when a matching document exists, so machines without a written-up page stay plain text and nothing 404s: link_docs A document collection, e.g. site.typewriters link_data_key Key on the data item to match on, e.g. "serial_number" link_doc_key Front-matter key on the document to match, e.g. "serial" link_column Which column becomes the link, e.g. "model" Every cell carries data-col="", which is how main.scss targets columns for width and wrapping. The previous markup was targeted with :nth-last-child(), which silently broke the moment a column was added or the optional image column appeared. A leading thumbnail column is added automatically if — and only if — at least one item has an `image` field, so a collection with no photos yet degrades to a plain table rather than a column of empty cells. NOTE ON KEY NAMES: never name a data key `size`, `first`, or `last`. Liquid treats those three as command methods, so when an item happens to *omit* that key, `item["size"]` silently returns the number of keys in the hash instead of nil — rendering e.g. "8" where a dash belongs. This is why typewriters use `body_size` and pocket watches use `watch_size`. {% endcomment %} {%- assign col_defs = include.columns | split: "," -%} {%- assign placeholder = include.empty | default: "—" -%} {%- assign has_images = false -%} {%- for item in include.items -%} {%- if item.image -%}{%- assign has_images = true -%}{%- break -%}{%- endif -%} {%- endfor -%} {%- assign sortable = true -%} {%- if include.sortable == "false" -%}{%- assign sortable = false -%}{%- endif -%}
{%- if has_images %}{% endif -%} {%- for def in col_defs -%} {%- assign parts = def | split: ":" -%} {%- assign key = parts[0] | strip -%} {%- assign label = parts[1] | default: parts[0] -%} {%- endfor -%} {%- for item in include.items -%} {%- assign doc = nil -%} {%- if include.link_docs and include.link_data_key and include.link_doc_key and include.link_column -%} {%- assign match_val = item[include.link_data_key] -%} {%- if match_val and match_val != "" -%} {%- assign doc = include.link_docs | where: include.link_doc_key, match_val | first -%} {%- endif -%} {%- endif -%} {%- if has_images -%} {%- endif -%} {%- for def in col_defs -%} {%- assign key = def | split: ":" | first | strip -%} {%- assign value = item[key] -%} {%- assign is_link_col = false -%} {%- if doc and key == include.link_column -%}{%- assign is_link_col = true -%}{%- endif -%} {%- endfor -%} {%- endfor -%}
Photo {%- if sortable -%} {%- else -%} {{ label | strip }} {%- endif -%}
